# Seat-Work (`tetycoon/seat-work`) — Service-First Chair Repair, Deep Cleaning & Service Management System

> We provide professional chair repair and servicing for all types of chairs. Our services include seat repair, cushion replacement, upholstery work, wheel replacement, hydraulic repair, armrest repair, backrest repair, and complete chair servicing. We focus on restoring comfort, improving durability, and giving old chairs a fresh, reliable finish.

Repository: `https://github.com/tetycoon/seat-work.git`

---

## Quick Start

### Option 1: Instant Zero-Build Preview (No Node.js Required)
Open [live-preview.html](./live-preview.html) directly in any browser to use the full interactive Customer Website, Team Service CRM, and PDF Blueprint Map immediately.

### Option 2: Full React + Vite + Tailwind CSS + Framer Motion Development Server
```bash
npm install
npm run dev
```

### Option 3: Push to GitHub (`https://github.com/tetycoon/seat-work.git`)
Run the included PowerShell deployment script:
```powershell
.\push-to-github.ps1
```
Or via standard Git commands:
```bash
git init
git branch -M main
git add .
git commit -m "feat: build Service-First Chair Repair, Deep Cleaning & Corporate AMC System"
git remote add origin https://github.com/tetycoon/seat-work.git
git push -u origin main
```
